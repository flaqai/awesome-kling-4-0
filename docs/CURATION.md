# Curation, Inspiration and Originality

[Home](../README.md) · [Prompt catalog](../prompts/README.md) · [Contributing](../CONTRIBUTING.md)

This repository studies public prompt libraries to identify **missing production problems**, then writes new Kling-oriented recipes from a blank page. External repositories are taxonomy references, not text sources.

## What may be carried across

- A broad use-case label such as automotive, livestreaming, industrial process or match cut.
- A general production problem such as identity consistency, reference assignment, editing or extension.
- A public contribution pattern such as a visible issue form and transparent review states.

## What must be newly authored

- Title, story, characters, products, locations and prop design.
- Shot order, timing, camera path, action logic, dialogue, audio and constraints.
- Descriptions, swap ideas, failure checks, thumbnails and preview media.

We do not import author lists, source-gallery metadata, promotional copy or third-party previews. A contributor must not disguise a close paraphrase by changing only nouns or adjectives.

## 2026-08-26 coverage review

The expansion from 24 to 40 recipes used the public category index of [AtlasCloudAI/awesome-seedance-2.5-prompts-skills](https://github.com/AtlasCloudAI/awesome-seedance-2.5-prompts-skills) as one coverage audit. It highlighted underrepresented workflows in this repository: object-centered match cuts, multi-image scenes, motion references, video revision, livestreaming, automotive, industrial, digital-human, pet, child-safe education, game, astronomy, compositing and previsualization.

The resulting 16 recipes were independently designed for this collection. They use new fictional people, generic products, original scene geometry and fresh timed direction. The external prompt text and media were not retained.

## Review states

| State | Meaning | What it does not mean |
|---|---|---|
| Recipe-only | Structure and rights declarations have been reviewed | The model has been benchmarked |
| Community-tested | A contributor supplied model, mode, date, setup and failure notes | The result is guaranteed across providers |
| Source-verified | A capability statement links to current official documentation | Every prompt using it has been tested |

Model behavior changes with provider, version, settings, references and moderation. Keep recipes and evidence separate, and update status without rewriting history.

## Duplicate and rights review

Before merging, search existing titles and distinctive phrases, compare the proposed shot sequence against nearby entries, verify media licensing and remove unsupported brand, likeness, voice or capability claims. When inspiration is unusually specific, disclose it in the pull request so reviewers can judge whether the new work is genuinely independent.
