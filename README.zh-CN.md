## 这个提示词库解决什么问题

普通图片提示词只需要描述画面；视频提示词还必须管理时间、动作、机位、连续性和声音。本项目没有搬运现成提示词，而是为可复用生产场景重新编写了 **24 条原创完整提示词**：

- 电影短片、双人及三人对白、克制的微表情表演；
- 产品广告、电商功能演示、真实感 UGC、本地商家宣传；
- 追逐、运动、材质变形、微缩天气与 VFX；
- 原创二维动画、时尚转场、音乐演奏与舞蹈；
- 食物 ASMR、旅行目的地、酒店空间、传统工艺；
- 科普解释、自然纪录片、无缝循环梗与公益短片；
- 中文、英文、日文、韩文、西班牙文原生对白写法；
- 图生视频、首尾帧、主体/元素参考、自定义多镜头的使用策略。

所有本地封面和示例图都为这个仓库全新生成，没有复用第三方图库缩略图。

## 60 秒开始使用

1. 从[提示词目录](prompts/README.md)选择最接近的实用场景。
2. 替换 `{花括号变量}`，人物、产品和道具的稳定特征不要写得模糊。
3. 根据目标选择文生视频、图生视频、首尾帧或主体参考。
4. 在可灵界面中匹配时长、画幅和多镜头设置。
5. 先测试主体动作，再一次只修改一个变量：动作、机位、声音或氛围。

## 可直接套用的可灵视频提示词模板

```text
[输出]
时长：{5–15 秒}；画幅：{16:9 / 9:16 / 1:1}；
模式：{单一连续长镜头 / 自定义多镜头}；整体质感：{写实 / 动画 / 商业 / 纪实}。

[连续性锚点]
角色 A：{成年年龄段、脸型、发型、体型轮廓、固定服装、标志细节}。
角色 B / 产品 / 道具：{固定形状、材质、颜色、标记和朝向}。
所有镜头保持上述特征不变。

[空间]
{地点、时间、天气、真实光源、前中后景位置、人物初始站位}。

[逐秒调度]
0–{x} 秒：{景别 + 角度 + 摄影机路径}。{一个主要动作}。{物理反馈}。
{x}–{y} 秒：{下一镜头或遮挡转场}。{一个主要动作}。{视觉/情绪回报}。

[表演]
{视线、呼吸、手部接触、情绪变化、动作重量和速度}。

[声音]
角色名（{语言、语气、音量、语速}）：“{简短对白}”
环境：{连续底噪}。拟音：{与接触同步的声音}。音乐：{何时进入、何时停止}。

[约束]
保持人物身份、服装、道具结构、运动方向和光线连续。
同一时间只让发言角色动嘴；不自动增加字幕、标志、水印或台词。
避免多余肢体、脸部漂移、橡皮动作、物体穿透、道具瞬移与无因果变形。
```

## 针对可灵的细化技巧

### 一个时间段只安排一个主动作

15 秒并不适合塞入十个剧情转折。三到四个清晰节拍通常更容易获得连贯结果。

### 把“同一个人”改写成稳定锚点

不要只写“同一个女人”。可以写成：“Mara：成年女性，银色短发，绿色椭圆眼镜，锈红色工装外套”，并在支持的模式中绑定对应主体。

### 分开写摄影机、主体与环境

```text
摄影机：顺时针慢速环绕 25 度，距离不变，地平线保持水平。
主体：瓶子固定不动，只有一滴冷凝水向下滑动。
环境：薄雾从左向右移动，柑橘皮完成一次平滑螺旋。
```

### 声音也是时间轴

给对白指定角色、语言、语气和顺序；给拟音指定精确接触时刻；说明什么时候不要音乐。多人场景要写“同一时间只让当前角色动嘴”。

### 用物理约束代替“顶级质量”堆词

“右手始终握住陶瓷杯把，杯底保持接触桌面”比“完美手部、杰作、电影感、8K”更能减少视频错误。

## 原创性与使用责任

- 本仓库的提示词、说明和场景均为独立创作，不复制其他提示词条目。
- 示例图为本项目全新生成；不含第三方图库、作者署名或开发者推广信息。生成意图和提示词记录在[图片素材清单](assets/images/README.md)中。
- 未经许可不要使用真实人物的肖像、声音、品牌资产、受保护角色或音乐。
- 商业发布前请审查产品宣称、广告披露、音乐与地点授权。
- 科普、纪录片和公共信息必须由专业人士核验；生成画面不能当作真实事件证据。
